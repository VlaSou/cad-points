CadPoints 0.6.3

CadPoints extracts, names, labels, tabulates, and exports coordinate points from selected CAD geometry layers in AutoCAD LT 2024+.

Install

Install the bundle into the user application plug-in folder:

%APPDATA%\Autodesk\ApplicationPlugins\CadPoints.bundle

Restart AutoCAD LT after installation. If autoload is blocked, check APPAUTOLOAD, APPAUTOLOADER, SECURELOAD, and TRUSTEDPATHS.

Commands

CommandPurpose
CPSETTINGSConfigure source layers, columns, scales, naming, output layers, labels, table output, sampling, and contours.
CPEXPORTExtract points, create optional point entities and labels, export CSV, draw an optional table, and create approximate contours.
CPHELPPrint a short command-line help summary.

Default Units

Drawings are treated as millimetre-based drawings unless configured otherwise:

1 drawing unit = 1 mm

Default curve sample interval and contour interval are both 1000 mm. Drawing scale is used for point labels. Table scale is used only for table text and table geometry.

Source Layers

Configure source layers in CPSETTINGS. The included example drawing uses:

CP_POINTS_A
CP_POINTS_B

Naming

If the point naming pattern is empty, names are derived from the source layer suffix after the last underscore:

CP_POINTS_A => A001, A002
CP_POINTS_B => B001, B002

A custom pattern can use # placeholders, for example A-SO01-### or P-####.

CSV And Table Columns

The default column configuration is:

POINT_NAME:Bod;LAYER:Hladina;ENTITY_TYPE:Objekt;VERTEX_NO:Vrchol;Y_SJTSK:Y S-JTSK;X_SJTSK:X S-JTSK;Z:Z

Supported field IDs are POINT_NAME, POINT_NO, LAYER, ENTITY_TYPE, HANDLE, VERTEX_NO, Y_SJTSK, X_SJTSK, and Z.

S-JTSK

CadPoints does not transform coordinates. It assumes the drawing is already in the project coordinate convention. Y_SJTSK is exported from the AutoCAD X coordinate, and X_SJTSK from the AutoCAD Y coordinate.

Output Layers

CADPOINTS_POINTS
CADPOINTS_POINT_LABELS
CADPOINTS_TABLE
CADPOINTS_CONTOURS

Contours

Contour output is approximate segment interpolation from available geometry Z values. It is not a Civil 3D surface model or geodetic terrain model.

Troubleshooting

If CPEXPORT returns no points, check the source layer setting and verify that supported geometry exists on those layers. If curved geometry cannot be sampled in AutoCAD LT, CadPoints should skip or report the failing object instead of crashing.
