CadPoints 0.6.2

Commands: CPSETTINGS, CPEXPORT, CPHELP.

Default project units: millimetres. Drawing scale and table scale are configured separately.

Generated point names use either the source layer suffix, e.g. CP_POINTS_A => A001, A002, or a custom pattern such as A-SO01-###.

Troubleshooting: if the bundle does not autoload, copy CadPoints.bundle into %APPDATA%\Autodesk\ApplicationPlugins and restart AutoCAD LT. If CPEXPORT returns no points, check source layers. Contour output is approximate and not a Civil 3D surface model.
